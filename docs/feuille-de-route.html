Note 8Tableaux standard dans tous les écrans

  • Tri par colonne, largeur réglable, comme le Scanner
  • Colonnes à masquer ou à ajouter (clic droit sur l’en-tête, bouton « Colonnes »)
  • Choix retenus par tableau
  • Colonne « Ports ouverts » plus large : plus de ports affichés, puis « +N »
  • Note 20 : colonne « Type » dans le Scanner, changeable par clic droit (retenu par MAC)
Prochaine : 0.4.0

Note 9Style Mac et petite fenêtre

  • Allure d’app macOS native : barre latérale translucide, contrôles du système, mode sombre automatique
  • Fenêtre réduite : le panneau de droite défile de haut en bas au lieu d’être coupé

À confirmer : Mac natif complet, hybride (garder le bleu nuit) ou mode sombre seulement.

Prochaine : 0.4.0, après la note 8

Note 7Capture et inspection de paquets

  • Capture avec filtre (host, port, arp…), liste en direct
  • Détail par couche et vue hexadécimale
  • « Suivre le flux TCP », statistiques
  • Enregistrer et ouvrir des fichiers .pcap (compatibles Wireshark)

À décider : dans la 0.3.0 ou dans la version suivante. Réutilise la capture de la note 2.

Note 12« Suis-je sur un port PoE ? »

  • Ce Mac : port PoE ou non, courant fourni ou non, classe et puissance (d’après LLDP/CDP)
  • Tout appareil : état PoE de son port de switch par SNMP
  • Dans la fiche appareil, le Scanner (colonne PoE) et Switchs et ports

Note 13Réglages encore « Bientôt »

  • Notifications : événements, son, heures de silence, notification de test
  • Export et sauvegarde : sauvegarde quotidienne, restauration, formats par défaut
  • Raccourcis clavier modifiables
  • Aussi : anglais, Test SNMP, identifiants SSH et WMI, méthodes de découverte

Note 14Outils courriel et DNS

  • Super outil : un champ, toutes les vérifications utiles
  • Recherche MX, listes noires, DMARC / SPF / DKIM
  • Diagnostic SMTP et santé courriel d’un domaine
  • Recherche DNS enrichie, analyse d’en-têtes de courriel

Note 15État des grands services en ligne

  • Microsoft 365, Azure, Apple, AWS, Google, Cloudflare, GitHub, Zoom… liste modifiable
  • Page d’état officielle et test depuis ce réseau
  • « Panne chez eux » ou « problème chez nous », incidents en cours, notifications

Note 16Speedtest : choix du serveur

  • Serveur le plus proche ou choisi dans une liste, favoris, serveur personnalisé
  • Ookla par son outil officiel s’il est installé, serveurs ouverts (M-Lab, LibreSpeed), serveur du fournisseur

Note 17Bouton « Installer » pour les outils manquants

  • iperf3, telnet… installés par Homebrew dans Terminal, en un clic
  • Sans Homebrew : lien d’installation officiel ; rien sans clic de Dany

Note 18Bilan des switchs périmé

  • Un message d’un ancien scan (autre plage) disparaît ou passe en « ancien scan »
  • Même règle pour passerelle, VLAN, emplacements et « Ce Mac est branché sur… »

Note 19Préréglage de ports dans le Scanner

  • Clic droit sur « Ports ouverts » ou sur des appareils : choix du préréglage de Réglages
  • « Rescanner les ports avec ce préréglage », rappel près de « Lancer le scan »

Note 21Ressources : processeur, mémoire, réseau

  • Ce Mac : processeur, mémoire, débit par interface en direct
  • Appareils par SNMP : processeur, mémoire, trafic par port de switch
  • Sondes de Surveillance sur ces valeurs

SuiteAlertes par courriel et webhook
